# OnlineQuizManagementSystem
Full-stack Online Quiz Management System built with ASP.NET Core Web API, Entity Framework Code First, React, JWT Authentication, and Role-based Authorization. Teachers can create and manage quizzes. Students can attempt quizzes and view results.


🚀 How to Run Project 2

Open Visual Studio → open QuizPortal → press F5(run)
Open Command Prompt → go to frontend folder → run npm start. (automatically the browser will be opened)
Open browser → http://localhost:3000

To run tests:

Backend + Selenium → Visual Studio → Test → Run All Tests
Frontend Jest → Command Prompt inside frontend → npm test -- --watchAll=false

only selenium test needs both the backend and the frontend to be running
